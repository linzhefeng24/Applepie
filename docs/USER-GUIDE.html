开始前

先把浏览器最大化，慢慢练习一遍，再按录制时间表演示。界面最左边是总导航；证券筛选里的第二列「证券分类」只负责筛选股票，不是切换页面。

看不到下方内容时，把鼠标放在中间内容区的空白处向下滚动，避免只滚动表格内部。

指标位置：MACD、RSI、BOLL 在「证券筛选」下方的联动图表上；「证券分析」页主要提供 MA 均线开关。

1　登录、证券筛选：找股票、加自选、切换曲线

  1. 登录后，点击最左侧总导航中的「证券筛选」。
  2. 在它右边的「证券分类」一列，先点击「ETF」，观察表格只显示ETF；然后点击「全部证券」恢复。
  3. 在股票表格上方工具栏，找到占位文字为「代码 / 公司」的输入框，输入 AAPL。若没有结果，把旁边的行业选回「全部行业」。
  4. 在 AAPL 这一行，代码左边有星形图标。点一下就是加入自选；已经亮着表示已收藏，不需要再点。
  5. 在同一条工具栏点击「字段设置」，右侧会展开面板。在「搜索字段」输入「波动」，勾选对应指标，再点面板右上角 × 关闭。
  6. 点击表格的「代码」列标题，观察排序箭头变化；点击其他数值列标题也可以排序。
  7. 单击 AAPL 行，再向下找到股票表格下面的联动图表。
  8. 图表上方一排控件中，第一个当前显示「日」的下拉框就是频率选择。点开后选「5分钟」；再选「日」即可切回。
  9. 旁边的「主图」可选 BOLL，「副图」可选 MACD 或 RSI。录制时各切换一次即可。
  10. 若下面的图表不见了：股票表格上方工具栏最右边有面板形状图标，点击可恢复联动图表。

2　证券分析：看单只股票的详细表现

  1. 点击最左侧总导航「证券分析」。也可以在上一步联动图表标题行右侧点击「证券分析 ↗」。
  2. 页面标题下面，找到「研究标的」下拉框，选择「AAPL · Apple」。日期先保持默认。
  3. 往下找到价格图。在曲线上方的图表工具栏，点击「MA」开关均线；点击「日 K」切换为折线。
  4. 把鼠标移到曲线上，停留一两秒，展示日期和价格。
  5. 「收益分布」在价格图右侧；窗口较窄时会排到下面。
  6. 继续向下滚动，找到「历年行情指标」表格，展示各年的收益、波动和回撤。

3　证券对比：把几只股票放在同一张图里

  1. 点击最左侧总导航「证券对比」。
  2. 页面顶部日期框下面是一排证券复选框。默认已选 AAPL、GOOG、GLD，直接保留即可。
  3. 等待下方出现三条对比曲线，把鼠标放到曲线上展示数值。图表下面是收益、波动率、回撤对比表。
  4. 点击页面右上角「导出对比 CSV」，浏览器会下载文件。

4　组合风险分析：修改权重、查看风险

  1. 点击最左侧总导航「组合风险分析」，保留默认三只证券。
  2. 证券复选框下面有「AAPL 权重 %」「GOOG 权重 %」「GLD 权重 %」输入框。
  3. 把 AAPL 的40改为20。合计不足100%时会出现提示，风险结果暂时不显示。
  4. 点击这一行右边的「设为等权」，系统会自动平均分配。
  5. 下面会显示年化波动率、VaR、ES和最大回撤；再往下是回撤曲线、风险贡献表、相关性矩阵。
  6. 点击页面右上角「导出风险 JSON」下载结果。

5　组合优化：运行模型、保存报告

  1. 点击最左侧总导航「组合优化」。
  2. 页面左边是「优化参数」。上方股票代码按钮是标的池：高亮表示已选，再点一次会取消。初次演示保留默认五只，不要随意取消。
  3. 日期、权重上限和三个 λ 参数先保持默认。
  4. 向下滚动左侧参数区域或整个页面，找到最下面的「运行五模型分析 →」，点击。
  5. 等待右侧出现结果。在结果区域上方的一排模型按钮中，点击 MVSK、最小方差，观察权重变化。
  6. 向下滚动右侧结果，展示「模型横向对照」表格和相关性热力图。
  7. 回到右侧结果区域最上面，找到报告名称输入框，把原名称替换为「课程演示」。
  8. 点击输入框右边的「保存到报告管理」，等待出现「已保存参数与完整结果」提示。

6　策略回测：设置规则、模拟历史投资

  1. 点击最左侧总导航「策略回测」。
  2. 在左侧参数区域向下找到「滚动窗口 / 日」，填126；「调仓间隔 / 日」，填63；「单边交易费 / bps」，填10。
  3. 点击参数区域最下面的「运行样本外回测 →」。
  4. 等待右侧出现结果，展示「组合净值」图和回撤图。
  5. 继续往下找到「调仓审计」，展示信号日期、执行日期和费用。
  6. 在结果区域找到「导出 CSV」按钮，点击下载。

7　报告管理：重新打开保存的结果

  1. 点击最左侧总导航「报告管理」。在中间报告列表里，直接点击刚保存的「课程演示」标题文字。
  2. 打开后，报告内容上方右侧有「导出 Markdown」「完整 JSON」「打印 / PDF」。
  3. 「导出 Markdown」下载可阅读的文字报告；「完整 JSON」下载完整参数与结果；「打印 / PDF」打开浏览器打印窗口。
  4. 录制时选「导出 Markdown」即可。左上方「返回档案」可以回到报告列表。

8　数据中心：查询分钟数据并下载

  1. 点击最左侧总导航「数据中心」。
  2. 页面里面左边还有一列「导出证券」。先点它上方的「清空」，再勾选下面的 AAPL。
  3. 在中间区域顶部工具栏，把第一个当前显示「日」的下拉框改为「2分钟」。
  4. 把旁边「起始」与「截止」两个日期都设为2026-10-23，等待下方表格出现数据。
  5. 同一条工具栏右边有格式下拉框，选择 CSV，再点它右边的「下载数据（数字）」按钮。
  6. 点击页面中间顶部、与「历史数据」并排的「API 访问」标签，即可查看请求示例与 OpenAPI 链接。

9　数据质量审计：查看来源与异常记录

  1. 点击最左侧总导航「数据质量审计」。
  2. 在页面标题下面的「审计证券」输入框填写 AAPL，表格会只留下这一只。
  3. 展示表格里的无效记录、重复时间戳等计数。
  4. 向下滚动，展示来源文件、SHA256、复权及成交量说明。
  5. 点击页面右上角「导出审计 JSON」下载。

10　账户管理：修改资料、展示权限、退出

  1. 在最左侧导航栏靠下的位置，找到「账户 / 你的显示名称 · 角色」，点击。看不到时滚动左侧导航栏。
  2. 页面上方有「显示名称」输入框。修改名字，再点旁边的「保存资料」。
  3. 下面的「活跃会话」表格显示当前登录情况。录制时展示即可，先别点当前会话的「撤销」，否则会立即退出。
  4. 管理员继续向下能看到「用户权限」表格，「角色」列是下拉框。普通账户看不到这一部分。
  5. 最后点击页面右上角「退出登录」，回到登录页后结束录像。
练习与录制

先按本指南完整练一遍，再按约2分50秒的录制计划操作。按钮位置会随窗口大小换行；找不到时优先核对按钮文字。
