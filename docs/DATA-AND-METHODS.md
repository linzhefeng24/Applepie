# 数据与指标口径

## 数据精简

原始来源为用户 GitHub Release `data_v1`；`part1.zip` 发布 SHA256：

```
3228a7935ab3b8fffa857c44cddf2795f6b37e76e965ab2787d364afd435a693
```

文件是每标的一份 `*_clean_1min.parquet`，字段为 datetime、Open、High、Low、Close、Volume、source。选择 32 个熟悉且历史重叠较长的跨行业股票/ADR/ETF。选择是教学取样，不是基于收益择优，也不是随机或无幸存者偏差样本。

处理：稳定按时间排序；重复时间保留最后一条；排除非有限值、非正 OHLC、负成交量和违反 OHLC 高低关系的分钟；按源记录的日期聚合第一条开盘、最高价、最低价、最后收盘、成交量之和，保留每日分钟条数。没有按完整交易日补齐，也没有推断缺失分钟的成交量。

时间戳没有时区，保留其日历日期，不擅自解释为 UTC。source 来源标签原样保留。复权和公司行动信息没有提供，未自行调整拆股、合并或分红。

`provenance.json` 保存逐股行数、缺失分钟较多的日数、无效记录、日收益超过 25% 的警示和精简 CSV 哈希。异常提示不是复权修复，也不能证明数据已完全清洗。

## 统计

- 简单日价格收益 `r_t = close_t / close_(t-1) - 1`。
- 累积收益为连续收益复乘；年化复合收益为 `(1+总收益)^(252/n)-1`。
- 方差为样本方差（ddof=1），波动率为样本标准差乘 `sqrt(252)`。
- Sharpe 为日均收益 / 样本日波动 × `sqrt(252)`，无风险利率固定为 0。
- 偏度使用样本中心矩 `μ3/μ2^1.5`，超额峰度使用 `μ4/μ2²−3`，未做小样本偏差修正。
- 最大回撤包括区间初始资本作为高水位。
- 年度分组的首年从区间首个可用收盘开始；后续年度基期为区间内前一年最后可用收盘。部分年度不等于完整年度收益。
- 数据没有财报，因此 ROE/收入/利润/PE/PB/股息率没有计算基础。

## 对齐与组合

只用共同价格日期，无插值与前向填充。个别缺失日会让两个共同日期之间的收益跨越多交易日；仍按 252 个观测年化，是演示近似，界面披露被删日期数，不将其作为精准交易所日历回测。

组合收益为 `R w`。偏度/峰度直接从组合收益计算，**不是**将个股偏度/峰度加权平均。

- 等权：解析权重 `1/N`。
- 最小方差：最小化年化样本方差。
- 均值—方差：最大化年化均值减 `λ₂/2 × 年化方差`。
- MVSK：令 `z=Rw/s`，`s` 为估计窗口个股日样本波动率的均值（与权重无关）。最小化 `−E[z]+λ₂ μ₂(z)/2−λ₃ μ₃(z)/6+λ₄ μ₄(z)/24`。这是中心矩偏好的一种实现，非唯一标准。
- 风险平价：最小化各资产方差贡献占比与等份目标的平方距离，仍受权重上限约束，因此上限可能阻止完全风险平价。

统一不卖空、权重之和 1、单股权重上限。SLSQP 使用三个确定性起点。无法得到成功且可行解时回退等权并显式标记；成功只表示数值收敛，非全局最优保证。单个标的上限只在建立目标组合时满足，之后漂移持仓可越过上限，到下次调仓恢复。

实验室指标是估计区间内每日恒定权重组合的毛收益描述，不是执行真实调仓策略的样本外收益。

## 回测时序

设价格数组为 `P[0..T]`、收益为 `r[t]=P[t+1]/P[t]-1`。执行日前的信号必须留出一个完整收盘的延迟：

1. 在持有收益 `r[t]` 之前，训练窗口为 `r[t-lookback-1 : t-1]`。
2. 最后训练收益的结束日期为 `P[t-1]` 日期。
3. 在下一价格日期 `P[t]` 的收盘执行。
4. 第一段持仓收益是 `P[t+1]/P[t]-1`。

每隔指定共同交易日重新估计。其余日期权重随价格漂移，不假设每天免费重新平衡。

费用为 `单边 bps / 10000 × Σ|目标权重−漂移权重|`，净收益乘数为 `(1−费用率) × (1+持仓收益)`。第一次从现金建仓计费，期末不计清仓。累计双向换手是上式绝对权重变动总和，不除以 2。

对照组使用相同区间、调仓日和费率；等权样本组合是研究基准，不能称作市场指数。未建模分红、税、冲击、滑点、停牌执行、下单数量、退市和融资，不用于实盘执行。
