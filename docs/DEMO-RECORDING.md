# 第二次作业：录制操作脚本

交付是完整前后端源代码 + 本人录制、不超过3分钟的操作视频，所有附件合计不超过100M。当前有10个独立功能路由：`/` 证券筛选、`/stocks` 证券分析、`/compare` 证券对比、`/risk` 组合风险分析、`/lab` 组合优化、`/backtest` 策略回测、`/reports` 报告管理、`/data` 数据中心、`/quality` 数据质量审计、`/account` 账户管理。登录注册另计。

## 录制前准备（不计入录像）

1. 解压最新完整安装包，执行 `bash run.sh`，等待显示已启动。首次安装、依赖下载、分钟数据导入放在录制前完成。
2. 浏览器打开脚本给出的地址，默认 http://127.0.0.1:4173。首次创建自己的管理员账户；准备好登录。禁止拍摄密码、数据库凭据或私有配置。
3. 用同一浏览器预览十个页面，等待证券筛选显示“指标32/32”，检查图表和下载。不要在正式录制中刷新整个页面，以复用已加载的公开行情缓存。
4. 优化/回测预演一次确认机器耗时。使用默认5只证券，最大权重40%；回测调仓间隔改为63，窗口126、费用10bps。较慢机器可把优化/回测区间缩到2024-01-01至2026-10-23，正式录制仍展示真实运行结果。
5. 预存一份报告作备用，不清除源数据。关闭无关窗口和通知，浏览器缩放80%—90%，保证参数、曲线和结果表能同屏展示。
6. Windows可用OBS窗口捕获或Win+G。建议1280×720、30fps、H.264、约1.5—2Mbps，AAC音频96kbps。目标视频约35—45MB。必须由本人实际操作录制；不编造结果或界面状态。

## 约2分50秒的操作顺序

| 时间 | 页面 | 操作与解说重点 |
|---|---|---|
| 0:00–0:08 | 登录→证券筛选 | 用自己的账户登录：“这是基于真实历史行情的APERTURE金融研究终端。” |
| 0:08–0:25 | 证券筛选 | 切换ETF/股票、选择字段、点击一列排序；给AAPL加自选；选择AAPL并切换日线与5分钟，移动鼠标显示OHLCV。展示紧凑筛选、资产类别、可选指标、自选与频率。 |
| 0:25–0:40 | 证券分析 | 打开AAPL，切换价格/技术指标，滚动展示年度指标、收益分布与财务“未提供”。强调行情指标来自数据，不编造财报。 |
| 0:40–0:53 | 证券对比 | 保留AAPL/GOOG/GLD，移动鼠标看统一基期曲线；展示共同日期区间、收益/波动/回撤表；点“导出对比CSV”。 |

| 1:08–1:30 | 组合优化 | 展示证券和约束，点“运行五模型分析”；结果出来后切换MVSK/最小方差，展示权重、五模型对照和相关性热力图；输入报告名“课程演示”并保存。 |
| 1:30–1:53 | 策略回测 | 调仓间隔63，展示窗口126、费用10bps；点运行，展示净值/回撤、调仓审计与信号日期；点“导出CSV”。说明是滚动样本外回测，计交易成本。 |
| 1:53–2:06 | 报告管理 | 打开刚保存的“课程演示”，展示参数和完整结果，导出Markdown或JSON；若演示删除，删除预先准备的临时报告。 |
| 2:06–2:23 | 数据中心 | 选择AAPL、2min、2026-10-23至2026-10-23，展示真实分钟数据；下载CSV/JSON，打开“API访问”展示请求与OpenAPI。 |
| 2:23–2:33 | 数据质量审计 | 搜索AAPL、查看异常计数、来源和SHA256，导出审计JSON。说明默认附最近60个记录交易日分钟子集。 |
| 2:33–2:46 | 账户管理 | 修改显示名称；展示会话列表和管理员角色设置。演示权限时选择提前创建的普通账户；保留至少一个管理员。最后退出登录，回到登录页。 |
| 2:46–2:50 | 结束 | “系统包含10个功能页面，19个独立服务，支持历史数据访问、量化研究和按用户隔离的报告保存。”停止录制。 |

目标是覆盖全部功能模块和关键交互，不是逐个修改所有模型参数或点击每个导出格式。切换页面时以实际完成为准；如果计算使总时长超标，先缩短分析区间再重录。若课程允许剪辑，可剪去纯等待时间，并保持操作和结果的真实对应；若要求连续录制则按预演耗时调整节奏。

## 提交前检查

- 播放视频确认十个页面都能辨认，关键运行结果确实出现，没有黑屏或泄露口令；文件时长小于180秒，建议留5—10秒余量。
- 提交最新 `APERTURE.zip` 和自己录制的MP4即可。ZIP含完整源码、精简数据和已校验的Scala运行依赖；不需要再提交node_modules、虚拟环境、原始1.6GB数据包、数据库目录或.git。
- 两个文件合计低于100,000,000字节。若使用PowerShell，可运行：`(Get-Item .\APERTURE.zip, .\demo.mp4 | Measure-Object Length -Sum).Sum`。
- 推荐视频控制在45MB以内，源码完整包约42MB，合计约87MB；以实际字节数为准。ZIP本身不是离线安装器，首次启动仍需要安装其余依赖。
