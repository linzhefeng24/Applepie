原创卡通死神角色的第一版概念图。

## 当前版本：现代都市楼顶

现代日本城市夜景，铁丝围栏、空调外机、天线与雨后楼顶。保留角色形象，用冷色调和强烈明暗对比营造悬疑氛围，作为后续 5 秒视频的首帧。

![墨鸦角色设定图](images/ink-raven.png)

## 角色特点

- 不对称墨圈眼与暗金色眼睛
- 一对笔尖角，其中一根断裂
- 外侧墨黑、内侧泛黄的书页翅膀
- 随身迷你笔记本，喜欢吃橡皮擦
