# 墨鸦 · Ink Raven

原创卡通死神角色的第一版概念图。

![墨鸦角色设定图](images/ink-raven.png)

## 角色特点

- 不对称墨圈眼与暗金色眼睛
- 一对笔尖角，其中一根断裂
- 外侧墨黑、内侧泛黄的书页翅膀
- 随身迷你笔记本，喜欢吃橡皮擦
