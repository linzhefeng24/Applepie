# 至少1000轮真实参数更新

用户明确要求至少1000轮；这里定义一轮为完整200–1100ms训练窗口的一次前向/反向传播及一次Adam参数更新。第0轮基线不计入1000，之前12/16等短试验也不计入。本长训练从已完成原始全网络检验的保守候选（stage2第5步）暖启动，优化器重新初始化，额外完成至少1000次更新。

保持原0.0125ms HH积分步长、硬上穿脉冲前向，采用代理导数、200ms截断BPTT、每1ms反向状态伴随裁剪，23类细胞共享207变量。损失为训练u(t)MSE+0.1×相对基线参数偏移平方均值；偏移硬限±20%。相同目标、全局3倍时间映射、固定MN肌肉池和读出。留出段不选择参数。

只计算到训练窗口结束是利用因果性省去无梯度贡献的未来状态，并非缩短训练数据或把小批次当一轮。训练时仍包含完整0–200ms预运行，持有连续状态，不在窗口内重置神经元。

GitHub Actions每个任务至多50次更新，每10次上传带SHA的不可变检查点，并更新progress.json；任务间自动恢复完整Adam一二阶矩、参数、步数和最佳状态，再派发后续任务，直到至少1000次完成。不会因为损失不下降而提前停止。中断不把未保存/未完成更新算入轮数。

第一任务可用2次更新验证保存与自动续训，随后每任务50次；这不是把2次当作完成。progress.json中complete只有在completed_updates≥1000时才能为true。运行结束后自动执行原始3988细胞硬脉冲网络验证并保存候选，训练完成不自动等于全部神经现象或左右交替已通过。

进度文件和每段检查点由GitHub任务持续更新，训练不依赖当前聊天保持开启。检查点保存在regularized-bptt-1000-20261115草稿Release；代码和progress.json记录实际计数、文件哈希和当前任务链接。
