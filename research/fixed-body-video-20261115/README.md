# 固定躯干、保留脚地接触的同输入回放

按用户要求将物理果蝇的根自由关节移除，并以参数文件中的初始平移及四元数作为固定根位姿。腿关节、肌肉激活动力学、重力、碰撞、摩擦和地面接触求解不变；不是每步重置位置，也不指定腿轨迹。躯干由外部固定支撑，不能用于证明自由行走或自平衡。

使用上一段DN_drive的实际神经脉冲和同一MN→肌肉映射，不重新调参。render_fixed.py重新积分身体并输出身体、神经链及同步视频。results/report.json记录位姿漂移、接触、肌肉与关节运动、模型及输入SHA。

结果ZIP包含三个视频、身体状态、验证报告和`updated_02_code/`。观看视频不需要安装依赖。需要自行重算时，将`updated_02_code/`内的文件复制到上一份完整模型包的`02_code/`，保留原`01_model/model.yaml`，运行 `python 02_code/run.py demo --experiment DN_drive --fixed-body`。本结果ZIP不重复包含未改变的大模型文件及神经状态数据。
