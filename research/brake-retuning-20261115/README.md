# BRK持续输入、短暂运动端响应：手动调参

前轮3988细胞扩展图和原参数保持；本轮先分解实际早/晚输入，再逐次手动选择参数，无优化器、强制放电或任意时间曲线。

已发现：IN07B001早期收到IN17A001、IN19A014、IN03A001等兴奋，但这些来源后期沉默；直接BRK源仍持续。既有脑参数将BRK共享source_gain设为0.5。候选r1只将已有BRK→IN07B001末端效力×2.5，保留源细胞生理、全部结构计数和符号，避免同时增大脑内停止通路。该末端参数未经实测，不能因招募成功就当作真实值。

运行示例：`python run_probe.py BRK configs/brake-terminal-r1.json terminal-r1`。control、MDN、MDN+BRK采用同一参数组及前轮相同刺激协议。完整脉冲保存，额外记录实际胞体/轴突电压、Ca、电流和电导。无刺激对照逐元素比较旧全网脉冲，避免形成新自主活动。

这里仍未接身体/感觉闭环，不能把持续MN活动直接当作制动成功。所有结果（包括失败）按tag保存；候选均暂不替换主参数库。

后续接口支持`--duration-ms 2600`在原刺激结束后检查恢复，及`--ablate-type IN07B001`只关闭被调的中继。可用相同3988图分别运行baseline-r9和候选的PFL3L，检验方向响应；其他刺激协议从已保存原实验读取。R2已使左右IN07B001晚期仍响应，但也募集E1候选家族，不能仅凭此宣布制动通过。AN19A018末端参数作用于完整注释类型家族，实际刺激仍限原先6个已选BRK。
