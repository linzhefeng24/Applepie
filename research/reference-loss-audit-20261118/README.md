# 参考关节轨迹零损失检查

结论：通过。去掉正则项后，将参考关节轨迹作为预测输出代入实际训练使用的损失计算，结果严格为0.0。

实际损失为 `mean((q[:, joint_ids] - target[:len(u)])**2)`，使用弧度。当前完整训练包含4000个物理步、66个腿部关节，共264000个角度误差项；评估时间为每步积分后的0.0001～0.4秒。不是仅比较20段的末端，不进行相位对齐、动态时间规整或按预测自动缩放目标时间。

独立读取历史原始 `retimed_reference_5000Hz.npz`（2001帧、0～0.4秒），核对66个关节名称与qpos索引，再插值到训练的4000个时间点。原始全部关节角数据与原AB模型YAML中的参考表逐元素相同，插值结果也与训练目标逐元素完全相同，最大绝对误差0.0。来源文件的SHA256和字节数记录在results.json；仓库中的原始AB模型压缩包包含与其等值的全部66关节参考表。

测试调用未修改的 `JointContext.loss(..., coefficient=0)` 和 `NativeWhitebox.objective`；只在独立诊断实例中注入预先知道的q轨迹，跳过神经输出和物理积分。这是在检查损失函数，不是在证明肌肉输入能够实现该参考轨迹。正在运行的训练代码没有修改。

这项检查没有推翻此前的梯度审查：目标值计算正确，不代表代理反传和物理VJP准确。损失也确实没有直接约束身体位置/高度，因此仅身体下沉不会直接增加该角度损失。
