# MaleCNS嗅觉结构与成年细胞生理约束

2026-11-19，正在建立结构和参数证据基础。本目录不是已完成校准的全嗅觉仿真。

`extract_network.py` 已实际读取并SHA256核对MaleCNS v1.0原始注释、递质及筛选连接表，提取8,286个候选细胞、1,492,168个有向细胞对、6,411,933个解剖突触计数。包括ORN2639、PN686、LN420、KC4064、MBON97、APL2、ALIN24、ALON14和340个接触KC/MBON的DAN候选。候选范围较宽，不能将全部DAN自动等同于目标气味的教学单元。

`neurons.csv` 保存原始bodyId、类型、脑侧、跨数据集类型注释和递质共识；`group-connectivity.csv`保存逐组连接计数；`network-audit.json`保存运行命令、依赖版本、范围与输出哈希；`sources.json`记录官方输入URL、大小和哈希。注释表211577行包含超出已连接重建网络的body，不能把行数当作有效全CNS神经元数。连接表为minconf0.5 significant-only，缺边不代表真实不存在；递质预测未直接转换成固定符号。

完整提取边在忽略目录`cache/edges.npz`，不提交大型二进制；可由上述脚本从官方原始表重建。需要Python、numpy、pandas、pyarrow。实际运行命令见audit。

已完成本轮动力学选型与参数证据整理，未开始网络参数拟合或完整仿真；不复用旧行走模型的生理参数。

## 已选动力学

以NEURON作为详细单细胞/小回路参考平台，采用电导型突触与空间结构：PN/MBON为被动树突加主动脉冲起始区；γ-KC优先采用成年电生理拟合的NaT/NaP/K多区室模板；APL为非脉冲分支电缆加局部递质释放；ORN加入受体/配体特异转导及适应；LN按类型区分脉冲与渐变响应；DAN采用脉冲动力学与独立多巴胺释放/清除状态。LN、DAN及其他KC/MBON亚型仍缺足够直接参数，保留待定，不用同一套HH或AdEx默认值冒充已标定细胞。

`model-spec.yaml`规定细胞/突触/学习接口、参数共享与未解决项。当前仅确定结构与机制选型，不是已完成全网可运行仿真。电缆段、SIZ位置与突触定位仍需要MaleCNS形态和空间突触数据；现有体对连接表不能提供这些信息。

## 直接核对的参数证据

`parameter-evidence.yaml`包含48条参数/参数组记录，其中15条明确待定；33条有数值的记录并非33个全部直接实测参数，也并非自由参数数目。分别标明成年测量、推算、形态拟合、借用模板、有效模型、搜索边界和实验操作条件。每条都有适用范围、单位、出处位置和不可泛化之处。

相同细胞类型共享主要参数；同一类型中允许有证据支持的有限变异。不能用统一倍数把EM突触数当成电导；不能将谷氨酸统一设负号；多巴胺必须单独建调制状态，不能把全部DAN边置零后视为已建模。γ1和α2的学习诱导条件不同，不能仅由统一恢复时间常数定义短/长期记忆。
