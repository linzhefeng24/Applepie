# 方程与接口

所有可调生理/结构/数值/显示值来自`01_model/model.yaml`。代码里的数组索引、零一和HH通道幂次属于方程结构，不是另一个参数表。

神经元为胞体与轴突两个耦合区室：

`Cs dVs/dt = gLs(ELs−Vs)+gc(Va−Vs)+gE(EE−Vs)+gI(EI−Vs)+INaP+Iexternal`

`Ca dVa/dt = gLa(ELa−Va)+gc(Vs−Va)+INa+IK+ICa+ISK+Ibias`

Na/K遵循HH的m/h/n门控；门控速率的系数全部在参数文件。门控用Rush–Larsen更新，电压耦合用后向Euler二元线性求解；无阈值重置。阈值仅用来计数上穿脉冲。Ca输入与清除反馈到SK。

电导型突触为有延迟的双指数，按单事件峰值归一化。结构突触计数乘以全局每突触电导、类型共享效力、释放/受体增益。ACh正、GABA负；CNS Glu负是受体假设，不是所有细胞的实测结论。未知/单胺递质没有被伪装成快电导。

MN池平均脉冲率经过参数文件指定的因果一阶滤波，除以公共率标度并限幅，得到`u(t)`。每块肌肉的MN候选池和缺口显式记录；不能从该接口唯一推断单运动单位生理。

肌肉激活`a(t)`、力长/力速、被动力和力矩由MuJoCo3.3.2原生肌肉执行，具体系数在MJCF；`tau = J(q)^T F`，刚体满足`M(q) qdd = qfrc_smooth + qfrc_constraint`，包含重力、关节约束和地面接触。代码不以关节目标或旧A/B控制替代肌肉驱动。

单位：神经ms/mV/pF/nS/pA/µM；身体沿用原模型原生坐标与力单位，只提供已有长度转换，不猜测原生力是µN。神经输入和身体驱动在本包是单向耦合；接触可读取，但没有回接感觉神经元。
