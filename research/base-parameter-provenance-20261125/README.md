# 基础参数到底怎样得到：当前可核对版本的来源审计

本次只读取代码、校准配置与最终模型，不进行新仿真或参数修改。这里说的是目前可核对的重建→R2→后来完整包；不能据此恢复缺失的周一原始实现。

## 来源链

1. 连接结构：从公开MANC/MaleCNS导出神经元身份、有向突触计数和递质预测，建立图。
2. 电生理形式：重建为双区室电导模型，使用经典HH Na/K门控，另加简化Ca/SK/NaP及双指数电导突触。Günay 2015是详细果蝇建模的方法参考，不是当前代码完整继承的多区室ModelDB实现。
3. 初始数值：没有目标成年细胞数据的电容、离子电导、突触动力学等采用显式模型/工程先验。不是从EM连接组直接计算，也不能全部说成文献逐项实测。
4. 成年MN校准：用成年股胫屈肌快/中/慢示例输入电阻和静息特性约束漏电/反转等。未知EM亚型用中型参考，不代表已经识别为中型。
5. 现象调参：在上述起点调整细胞家族、特定通路、读出增益，形成R2；后来新增细胞按已有superclass模板/中位数赋值，再有MN/上游/身体调整。

## 17项细胞参数逐项说明

以下“初始”指重建代码DEFAULT/角色模板，非所有历史版本唯一初值；后来的手调值需查逐动作报告。

| 参数 | 起点或参考 | 怎样得到 | 哪些不是实测 |
|---|---|---|---|
| capacitance_soma_pF | 常规20；MN角色×2为40 | 简化区室容量先验与角色倍数 | 未由这些EM细胞膜面积重建，也非每个成年细胞实测 |
| capacitance_axon_pF | 2.5 | 简化轴突区室先验 | 同上 |
| leak_soma_nS | 非MN以Rin500MΩ构造；MN以300MΩ起再校准 | 下述电导公式及模型单细胞测量/数值拟合 | 非MN500是先验；成年Rin只能约束总响应，非唯一漏电 |
| leak_axon_nS | 总参考电导的15%，再参与MN校准 | 区室电导分配规则 | 15%没有逐细胞测量 |

## 成年MN校准具体怎样做

来源：Azevedo等，eLife.56754，成年股胫屈肌运动单位的示例参考。代码targets为快/中/慢Rin150/300/700MΩ，静息电位约−68/−60/−48mV；慢型约30Hz自发，快/中静息沉默。它们不是全部六腿MN的已确认单位身份。

`calibrate_adult.py`在单细胞模型中分别给−1、0、+1pA，取稳定段胞体电位，以ΔV/ΔI测模型输入电阻；用least_squares调整漏电尺度、漏电反转和耦合。原来的部分解漏电反转过度去极化，因此又运行`refine_intermediate.py`：固定候选NaP={0.3,1,3}nS与耦合={1,4,12}nS，约束漏电反转范围，再拟合尺度/反转，并对静息放电惩罚。

选中中型参考：leak_scale=0.5719406364200305，漏电反转−50.857904405099035mV，耦合4nS，NaP0.3nS；模型测RMP约−60mV、Rin约300MΩ、静息0Hz。这是**实验摘要约束的数值校准**，不是手动从论文抄一套全部参数，也不是唯一生理解。

代码先设置总参考电导 `gt=1000/Rin`（nS），`gLa=0.15*gt`，`gLs=gt−gc*gLa/(gc+gLa)`。300MΩ时gt约3.333nS；gc=4时gLs约2.8889nS，乘校准尺度后胞体漏电约1.65227294966nS，轴突漏电约0.28597031821nS。NaP/主动电流使模型总Rin不等于单纯1/gLs，所以最终以实际单细胞测量为准。

## 突触与离子反转参数

| 项目 | 当前完整包数值例 | 来源性质 |
|---|---|---|
| 兴奋上升/衰减 | 0.5/5ms | 全局有效突触先验，非逐边实测 |
| 抑制上升/衰减 | 1/30ms | 全局先验并经过调试；初始DEFAULT衰减25ms，不能混作始终30 |
| 兴奋/抑制每计数电导 | 0.012/0.006nS | 模型有效尺度与手调；初始DEFAULT的gi是0.025，不是每个突触都已测定 |
| 传导延迟 | 1.5ms | 全局先验，未按实际路径长度与髓鞘/轴突标定 |
| E_exc/E_inh | 0/−80mV | 有效受体反转先验，未逐靶受体标定 |
| E_Na/E_K/E_Ca | +55/−80/+120mV | 离子反转假设，不是每个目标成年细胞的实测浓度推导 |
| Ca清除alpha、SK半激活 | 0.0002、0.2µM | 简化模型先验，不能称为全面成年数据 |

连接组计数不等于突触电导。兴奋事件包含`count × ge × target_gain × source_release`，抑制事件另含源端抑制释放；递质预测决定模型符号仍包含受体假设，特别是中枢谷氨酸。不能将中枢符号自动移植到兴奋性谷氨酸NMJ。

## 新增细胞怎样赋值

11月19日扩展记录显式保存“借用谁”：例如EPG/Delta7借PFL3模板，DNb05/06借DNb08，DNg11借DNg13。`parameter_priors.json`标为borrowed_manual_model_prior_not_measured。这种借用是功能/类型近似，不表示相同电生理已验证。

用户后来完整包记录新细胞按superclass取已有参数中位数：MN用MN模板、感觉用感觉模板、其余按对应大类/缺省VNC模板。26,885细胞最终仅21个不同17维参数向量，所以不能说给每个细胞找到了一套独立可信生理参数。实际扩图赋值与后续手调须分阶段看。

## 肌肉端、身体端与“基础”区别

肌肉通道几何、强度、骨架、惯性和接触来自存档AB/legacy模型及其重建/估计，不是统一从连接组获得，也不等于完整原版FlyMimic六腿实测。MN→肌肉池有跨动物同源和功能类别估计，后来BANC补8池；18空池用外部AB输入。肌肉激活动力学继承并核对MuJoCo原生实现，模型方程来源可信不等于每块肌肉常数都已测。

NMJ读出最初共享20ms滤波/50Hz尺度；后来包改160ms/40Hz和逐通道增益。模型里的部分parameter_provenance仍写旧20/50，它是阶段来源说明，不是当前完整包实际读出值。160/40属于标定，不是公开实验给出的普适NMJ常数。

## 明确结论

基础来源是“真实连接结构 + 经典电导方程 + 显式工程先验 + 少量成年生理约束校准”，再叠加回路手调与模板扩展。主要可靠实验锚点之一是成年MN的输入电阻/静息特性；大部分DN/VNC主动通道、突触、区室和读出参数没有目标细胞的逐项实测。Günay/ModelDB提供方法参考不能替代本实现逐值溯源。
