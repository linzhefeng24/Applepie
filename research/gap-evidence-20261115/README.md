## 已核查的重要结论

1. 原381个已注释腿MN中，3474细胞脑图仅含2个，且不含本次选中的415个腿本体感觉细胞。不能只靠调参恢复被裁掉的闭环。
2. 从同MaleCNS版本重新提取12个腿部campaniform、403个chordotonal细胞的通路；全部结构上可在0或1个VNC intrinsic中继后达腿MN。它们是特定神经入口/已重建子集，不代表全体感受器。chordotonal标签不能直接认定hook/claw/club；campaniform标签不能决定应变方向。
3. 6个BRK通往374个腿MN，存在9870条两边路径；原3474图仅保留85条。现新增514细胞，建立3988细胞、485045有符号边的同动物扩展，完整保留旧图有符号/无符号子矩阵。尚未接入身体或感觉反馈；新增MN采用成年MN先验，不冒充已标定。
4. BRK原论文要求制动行为，不要求LBL40必须沉默。之前以LBL40残余放电作为BRK失败证据过强，应纠正。BRK→BON1已传到；真正VNC制动应检验角度依赖肌肉募集、支撑时锁腿、落地后锁腿。
5. DNg13步相门控论文提出的是候选回路/假设性相位活跃细胞，不是已测量到完整门控函数。不可把图7假设的相位激活直接写成确定机制。
6. 有限元论文摘要报告：仅靠地面反力可能不足以激活后腿femoral CS。当前接触力→饱和电流只是工程代理，尚缺内部肌肉力、几何、材料及CS取向到局部应变的标定。

## 已新增验证/诊断

- BPN+P9在同r9参数组下完成；双侧刺激的神经组合输出不等于单侧转向行为复现。
- BB对DNg97的抑制没有被阻断：左侧平均抑制电导10.66→14.17nS、胞体-62.62→-68.19mV、放电24.4→13.3Hz。抑制电流幅度反而变小可由驱动力下降解释，不能据此说抑制没到。
- DNg97共享胞体—轴突耦合12→18nS诊断试验未一致改善，保留但不采用；不能认定残余输出仅因耦合不足。
