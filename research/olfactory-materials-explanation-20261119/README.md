# 嗅觉学习材料解读与MBON→PAM符号核查

2026-11-19。范围：阅读用户上传PPT及HTML；附件Nature论文超过32 MiB工具读取上限，因此改读同标题、同DOI的Europe PMC公开全文。没有运行或审计PPT所述模拟代码，没有重新核算原始MAT数据。PPT结果均为作者报告，不能视为本次独立复现。HTML自述原始数据核验成功，也不等于本次核验。未改动神经模型、参数或训练。

## 1. 谷氨酸不等于固定兴奋或固定抑制

正负取决于突触后受体、离子反转电位、细胞状态及是否含多突触网络效应。阳离子型谷氨酸受体（例如NMDA型）可介导兴奋；谷氨酸门控氯通道GluCl在常见生理条件下可介导抑制或分流。代谢型受体还可能调节较慢过程。不能将哺乳动物皮层的常见符号规则直接推广到果蝇，也不能把全部果蝇谷氨酸连接都设负号。

Zhao等2018，eLife，doi:10.7554/eLife.31425，Figure4：激活M6使aSP13/PAM-γ5的GCaMP信号升高；50 μM D-AP-5显著阻断该响应。刺激后钙响应约2分钟衰减。文章解释为NMDA受体相关的兴奋性谷氨酸反馈。M6即MBON-γ5β′2a；aSP13即PAM-γ5。支持将匹配的M6→PAM-γ5反馈建模为兴奋，但实验在雄蝇求偶记忆/离体脑背景开展；不能据此断言所有MBON→PAM连接均兴奋，不能把钙响应持续时间当成单个突触的实测衰减常数。正文未证明用户连接组中每个PAM01实例都等同于实验靶细胞，ID需另行核对。

2024综述doi:10.1101/lm.053807.123：MBON-α1→PAM-α1回路涉及PAM-α1上的NMDA受体，但也表达GluCl，不能仅凭行为必要性就判定直接单突触净符号；作者保留间接通路解释。这个例子说明“有NMDA表达/敲低表型”不等于“已测定全部直接连接兴奋”。

Huang等2024 Nature的PPL1-α3中，Rdl（GABA_A）及GluCl-α分别敲低均破坏天生气味效价的双向编码。支持该PPL1细胞的抑制机制参与，不能反推出某条未识别MBON→PAM的符号。

## 2. PPT：从结构到学习

30页，2026-11-18，标题A Connectome-Constrained Model of Olfactory Learning in Drosophila。作者报告MaleCNS网络166,700神经元、25,582,938有向神经元对、124,177,617解剖突触。大部分神经元使用电流型LIF，dt=0.1ms，膜时间常数20ms，普通突触衰减5ms、延迟1.8ms。这是有连接组约束的功能模型，不是全部细胞生理参数都实测的全脑数字孪生。

主要处理链：气味分子特征和文献电生理锚点→随机森林预测ORN活动→泊松输入→嗅叶LN调节和PN→KC稀疏编码→KC→MBON输出；KC招募APL，APL提供抑制反馈。APL使用真实SWC形态并约化为7,122段，不能据形态真实就推断全部电学参数真实。全体97个MBON输出相加也不直接等于趋避行为，因为各MBON的下游与行为功能不同。

学习在KC→MBON可塑连接发生：气味留下KC资格迹，多巴胺作为教学信号调节权重；按DAN释放位置和接触距离施加空间核。PPT参数：抑制/增强迹5s和1s，系数均0.3，权重增益0.2–1.5，初值和恢复目标1.0；γ、α′/β′、α/β恢复时间常数分别1、6、48小时；空间σ=2μm，截断8μm。这些数值是PPT所用规则，不能当作各突触已实测常数。突触距离核本身亦需敏感性验证。

报告结果：奖惩配对、刺激时序改变可塑性方向、DAN消融、相近气味迁移、遗忘、再暴露、奖惩反转、密集/间隔训练。第27–28页明确承认间隔训练结果与文献不一致；第20页也保留M6惩罚响应方向的问题。这些应作为待验证/失败，不是已复现现象。

M6→PAM01普通突触衰减设500ms，而常规为5ms，理由是延长输入累加、支持内源PAM活动。它是校准的有效参数，非PPT提供直接生理测量；实验支持NMDA相关持续响应，并不直接证明500ms这个数值。需分别检查受体动力学、回返网络、细胞兴奋性及多巴胺调制机制，不能仅延长一个时间常数就认定恢复真实机制。

## 3. Nature论文：短期记忆如何门控长期记忆

Huang et al., Dopamine-mediated interactions between short- and long-term memory dynamics，Nature634,1141–1149(2024)，doi:10.1038/s41586-024-07819-w，PMC11525173。主要研究厌恶性条件化中的PPL1通路，不是专门验证PAM奖赏环路。

使用1kHz电压成像，研究5类PPL1和6类MBON。教学信号包含气味天生效价与已学习效价，可表现放电增加或降低。关键链为：KC→MBON-γ1pedc>α/β（MVP2，短期相关）受到学习抑制→该MBON对PPL1-α′2α2/PPL1-α3的抑制减弱→后者被去抑制→后续训练促进KC→MBON-α2sc/MBON-α3的持久可塑性。抑制少了导致下游活动更强，是去抑制，不是结构连接改成兴奋。维持γ1 MBON活动会损伤3小时记忆但不损伤5分钟记忆，是该反馈参与长期记忆的因果证据。

模型反Hebbian规则：KC活跃伴随DAN活动增强或降低，分别削弱或增强KC→MBON连接。此处关注相对基线的双向教学信号；不能把它简单等同于所有PAM/PPL1均遵守同一普适规则，也不能与PPT的刺激先后时序规则直接等号。

论文用连接组和86项放电率测量共同拟合。特定六轮训练中，360s间隔比60s或900s产生更强的α3持久可塑性；并非间隔越长越好。其解释是感觉适应与γ1短期记忆反馈的竞争。对原本有吸引力的气味训练后，10分钟再暴露能增强α3可塑性，2小时再暴露则减弱。消退不是在所有脑区/时间点都等价于恢复初始权重。

## 4. HTML：可约束什么，不能说明什么

静态解析嵌入JSON：11只纳入动物，实验组7/对照组4，2,579个ROI/细胞；4气味×6trial×46帧。0–9帧基线，10–45分析窗。迹线8bit量化至[-1,2]且可能裁剪，页面声称汇总统计使用原始float64；本次无原始MAT，不能独立验证此声称。

同动物跨trial有配准，不等于跨动物/连接组实例有身份匹配；缺细胞类别、脑区、ROI坐标、采样率、精确刺激时长、浓度、T6干预定义、行为读数。故尚不能指定某行就是KC或某个MBON，亦不能将ΔF/F直接作为Hz。需加入spike→Ca→荧光观测模型。

页面“相似度”采用逐细胞的刺激窗时间迹线Pearson相关，再跨细胞平均；这与跨细胞响应幅值向量的气味模式相关不是同一个量。两者不能混称为同一个“表征相似度”。负ΔF/F/响应下降也不能单独证明某条上游突触为抑制性。trial变化可能来自适应、漂白、状态或处理，未明确范式前不能都解释成学习。统计独立单位以动物为主，不能把2,579个细胞当作独立动物样本。

## 5. 建议讨论的具体问题

1. 按MBON类型、DAN类型和受体建立逐通路证据表；M6→PAM-γ5作为有功能/药理支持的兴奋性反馈，其他未明边保留符号不确定性，不一刀切。
2. 用M6激活/阻断、PAM-γ5电压或钙成像、受体敲低以及适当直接传递检验，对兴奋性反馈和持续响应机制做因果区分。
3. 同时观察MVP2、PPL1-α3和MBON-α3；做γ1反馈阻断/维持活动，检验短期→长期门控，而非只拟合遗忘曲线。
4. 匹配气味效价、浓度、CS/US时序和训练次数，比较60/360/900s间隔及10min/2h再暴露；同时量化神经活动与行为。
5. 先补HTML实验元数据与原始MAT，明确成像群体/时间标尺，再与模型输出比较。
