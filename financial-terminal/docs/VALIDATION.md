## 数值测试内容

1. 最大回撤包含初始资本。
2. 三、四阶中心矩计算。
3. 五模型权重和、禁止卖空、权重上限与最小方差对照。
4. 不可行约束和负费用拒绝。
5. capped simplex 投影约束。
6. 缺失价格按交集处理，无前向填充。
7. 训练窗口与一整个收盘的信号延迟。
8. 改变未来收益不改变既往回测与调仓。
9. 首次从现金建仓计费。
10. 调仓间持仓随价格漂移。
11. 成本增加会降低相同策略净值。
12. 相同输入的优化结果确定性。

## API 集成测试内容

- 返回 32 个股票与最新源行情。
- AAPL 全部 1,164 条数据库日线逐行匹配 CSV。
- Scala 个股统计与 Python 独立统计在收益、波动、Sharpe、回撤、偏度和超额峰度上误差小于 1e-9。
- 五种优化可行并收敛；回测四种策略，净值与总收益一致；每条调仓记录满足信号日 < 执行日 < 首个收益日。
- 无效股票、反向日期、重复股票、不可行上限、样本不足和无效报告返回 400。
- 自选持久化、报告参数和结果保存/读取一致、删除清理。
