# 功能范围与参考

实际查阅了 [OpenBB 官方公开说明](https://github.com/OpenBB-finance/OpenBB/blob/develop/README.md)，参考其历史证券数据、可视化、数据访问和应用接口的组织方向。Koyfin、TradingView、Bloomberg 的商业官网在当前网络策略下返回403，未将无法读取的页面当作已研究证据。未安装 OpenBB，也未引入其依赖或代码。

| 能力 | 本项目实际功能 |
|---|---|
| 证券浏览与筛选 | 股票 / 元数据中标明的 ADR / ETF、行业、自选、代码/公司检索、AND 数值条件、排序 |
| 指标工作表 | 20项可选字段、列顺序调整、三组预设、行高、浏览器保存显示配置、CSV导出；不足数据留空 |
| 变化曲线 | 年/月/日/5分钟/2分钟/1分钟，日 K / 收盘线、累计价格收益、区间回撤、20日滚动年化波动；日期区间、缩放、悬浮读取、PNG下载 |
| 技术指标 | MA20/MA60、BOLL(20,2)、MACD(12,26,9，柱×2)、Wilder RSI14、源成交量；截至日前真实历史预热 |
| 证券分析 | 年度收益风险、收益分布、双证券共同日期对比、数据质量和缺失财报说明 |
| 组合分析 | 2–10只选择、五种优化模型、约束、权重、相关性、收益分布、收敛信息 |
| 回测评估 | 滚动估计、信号延迟、权重漂移、成本、对照、净值与回撤、调仓审计及CSV |
| 历史数据访问 | 单只/多只/组合成分、日期查询、分页OHLCV、CSV/JSON、可选技术指标、下载保留精度 |
| 数据审计 | 来源与SHA256、原始分钟/拒绝/重复/稀疏日/跳变记录、审计JSON、源Release链接 |
| 接口使用 | 各服务独立API文件、真实HTTP、OpenAPI JSON、可复制curl、错误与请求约束 |
| 研究记录 | 自选持久化，报告保存/查询/删除，参数和完整结果JSON/Markdown，浏览器打印 |

当前资料只覆盖32个历史标的，没有未导入市场的数据。实时行情、订单簿、交易执行、账户资产、新闻、财报、期权与宏观数据需要对应数据和授权接口，本版未接入，不提供虚假的实时状态或占位结果。它是完整可运行的历史研究与量化软件，不是交易经纪平台。

默认分钟数据库保留最近60个交易日真实记录，可从原始包导入全部分钟历史；查询按真实可用范围与5000根上限约束，不从日线反推分钟价格。
